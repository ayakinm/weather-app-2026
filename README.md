# Weatherly

A responsive weather dashboard built with JavaScript, Node.js, and Express. Search for a city to see current conditions, the next 24 hours, and a seven-day forecast. Switch between Celsius and Fahrenheit or use your device's location.

Weather and city search are powered by [Open-Meteo](https://open-meteo.com/), a free API that does not require an API key.

## Get started

Requires Node.js 18 or newer.

```sh
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000). To run with automatic server restarts during development, use `npm run dev`.

## Tests

```sh
npm test
```
